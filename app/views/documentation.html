geo-frete

Open-source REST API that computes the real driving-route distance between two Brazilian addresses.

address text → street correction CNEFE → house number → coordinates CNEFE / Nominatim → road route OSRM → km + minutes

The API knows nothing about prices, customers or orders: it reports distances, travel time and how precisely each address was located. Business rules belong to the consumer.

Why not "straight line × 1.3"?

Measured on 299 random pairs of real house numbers in Limeira/SP, routed by car:

1.46×median route / straight line
11.5%median error of the ×1.3 estimate
43.5%of pairs within 10% with ×1.3
−63%worst underestimate

Authentication

Every route except /api/v1/health requires Authorization: Bearer <api-key>. Responses always use the envelope {"data": ..., "message": ""}.

Endpoints

POST/api/v1/distance

Road distance between two addresses. Send lat/lng you already know to skip geocoding.

curl -X POST /api/v1/distance \
  -H "Authorization: Bearer YOUR_KEY" -H "Content-Type: application/json" \
  -d '{
    "origin":      {"street": "Rua Senador Vergueiro", "number": "500", "neighborhood": "Centro",
                    "city": "Limeira", "state": "SP"},
    "destination": {"street": "Rua Barão de Campinas", "number": "300", "neighborhood": "Centro",
                    "city": "Limeira", "state": "SP"}
  }'
{
  "data": {
    "distance_km": 0.56, "duration_min": 1.2, "straight_line_km": 0.17, "method": "route",
    "origin": {"lat": -22.562669, "lng": -47.401122, "precision": "interpolated", "source": "cnefe",
               "street_used": "Rua Senador Vergueiro", "street_corrected": false, "snap_distance_km": 0.003, ...},
    "destination": { ... },
    "requires_confirmation": false
  },
  "message": ""
}
precisionmeaning
providedthe client sent the coordinates
numberexact house number found
interpolatedestimated from neighboring numbers of the same street
streetonly the street found: confirm on a map
neighborhoodonly the neighborhood found: confirm on a map

GET/api/v1/streets/suggestions

Street-name autocomplete from the local base, fast enough for every keystroke.

curl "/api/v1/streets/suggestions?street=senador+verg&city=Limeira&state=SP" \
  -H "Authorization: Bearer YOUR_KEY"

{"data": {"suggestions": [{"name": "Rua Senador Vergueiro", "score": 0.9}], "available": true}, "message": ""}

GET/api/v1/health

No authentication. Database and routing-engine status.

Errors

statuswhen
400invalid body; data.errors lists every problem
401missing or invalid API key
422ambiguous_street (with suggestions; resend with "street_confirmed": true) or not_found
429rate limit exceeded
503geocoding provider temporarily unreachable

An unavailable routing engine never fails a request: the answer falls back to "method": "estimate".
